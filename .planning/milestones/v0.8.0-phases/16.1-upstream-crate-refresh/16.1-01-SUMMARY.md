# Phase 16.1 Plan 01: Upstream Crate Bump + R-Matching Behaviour Lock Summary

## Accomplishments

- Bumped `anofox-statistics` to `0.4.6` and `anofox-regression` to `0.5.16` in `Cargo.toml`; `Cargo.lock` resolves exactly those two versions (verified via `grep`); `cargo fmt`/`cargo clippy --all-targets -- -D warnings` clean; extension rebuilt with `uv run maturin develop --release`.
- Fixed the two previously-failing Tweedie smoke tests (`test_tweedie_group_by`, `test_tweedie_over`) by encoding the new NaN-aic/bic behaviour for non-closed-form `var_power` (anofox-regression 0.5.14 #43) via a new `nan_ok` kwarg on the `has_valid_numbers` helper; added `test_tweedie_closed_form_power_group_by` to cover the closed-form `var_power=2.0` case. Documented the closed-form rule in `tweedie`/`tweedie_summary`/`tweedie_formula` Python docstrings and the Rust `PyTweedie` class/`aic`/`bic` getter docs.
- Locked 9 anofox-regression 0.5.14/0.5.15 behaviour changes with R-reference tests: Ridge λ>0 sandwich SE with NaN t-test (#37, `tests/test_models.py::TestRidge`), OLS `log_likelihood`/`aic`/`bic` (#41), no-intercept uncentred-TSS R2/adj-R2/F for OLS and WLS (#38), constant-column-is-the-intercept (#39), RANSAC inlier-fit statistics (#35, also rewrote `test_n_observations` for the new `n_observations == n_inliers` semantics), NegBin dispersion=1 SEs (#49), NegBin/Poisson logLik/AIC (#42), Gamma Pearson-dispersion SE/AIC (#43), a genuinely-rank-deficient GLM aliasing case (for contrast with #39), and Theil-Sen collinear-column aliasing (#50).
- Locked 7 anofox-statistics 0.4.3 behaviour changes with R-reference tests: Shapiro-Wilk n<=11 exact p-values (#7), Kendall tau-b tie correction (#8), exact binomial interval/p (#9), one/two-sample proportion intervals (#10), Fisher exact p-value and sample odds ratio (#11), exact two-sided Mann-Whitney (#12), and rank-test centre/all-tied p=1 edge cases (#13).
- Proved non-finite (NaN/±Inf/constant) input never panics across 10 hypothesis-test classes via a parametrized sweep (`tests/test_nonfinite.py`, 43 tests collected under `pytest -k nonfinite`), plus Wilcoxon/Mann-Whitney/Kruskal-Wallis exact-value regression tests with ±Inf inputs and an expression-layer non-finite-filtering equivalence check for `ps.mann_whitney_u`.
- Performed the UPST-02 assertion audit across all files the research flagged as potentially affected — no pre-existing assertion needed tightening (see table below).
- Full gate green: `cargo fmt --all -- --check`, `cargo clippy --all-targets -- -D warnings`, and `uv run pytest tests/ -q` (734 passed, 5 pre-existing skips, 0 failed).
