- Copied `tests/fixtures/wilcox_ci_reference.csv` byte-identically from upstream release commit
  `3ab3bec` (`~/projects/rust/anofox-statistics-rs`) — sha256
  `e51fd41b79d5e43274cfe86378e71395b2a96461347294add8e425c52863c296`, 126 data rows + header,
  matching the planner's recorded prefix exactly.
- `test_hodges_lehmann_matches_r` parametrizes `MannWhitneyU`/`WilcoxonSignedRank` over all 126
  rows (kind, alternative, continuity correction, exact, conf_level, mu), asserting `estimate`
  and `conf_int` match R `wilcox.test(conf.int=TRUE)` to `tol * (1 + |ref|)` (1e-12 exact /
  1e-9 asymptotic), including correct-sign-of-infinity one-sided interval bounds.
- `test_hodges_lehmann_fixture_integrity` pins the 126-row count and the fixture's full sha256.
- Locked the exact-distribution-overflow fix (0.4.5 #19): 40-vs-40 rank-sum gives
  W=756, p=0.6771573878425421 (exact) vs p=0.6755238797807038 (asymptotic); 70-difference
  signed-rank gives V=1525, p=0.09908340663363724.
- Locked the exact-gating thresholds: above n1*n2=10,000 (rank sum, tested at 12,000) or 300
  non-zero differences (signed rank, tested at 320), `exact=True` is silently ignored
  (p-value identical to `exact=False`); below threshold the two differ by >1e-4.
- `test_mcnemar_exact_large_counts_matches_r` parametrizes 10 R `binom.test(b, b+c, 0.5)`
  reference cases up to b+c=1,000,000 — every p-value finite, swap(b,c)-symmetric, and
  within relative 1e-9 of R; `statistic == b + c` confirmed.
- `test_large_sample_hodges_lehmann_completes_in_o_n_memory` runs the Hodges-Lehmann CI on
  20,000 observations per group (previously ~3.2 GB / O(n^2) memory) and asserts the interval
  brackets the estimate and the estimate recovers the true 0.1 shift within 0.02.
- `test_tost_wilcoxon_alpha_above_half_does_not_panic` confirms `alpha=0.6` on both
  `ps.tost_wilcoxon_paired` and `ps.tost_wilcoxon_two_sample` returns a valid struct row with
  no exception.
- `test_expression_schema_mann_whitney_and_wilcoxon_omit_estimate_ci` locks the pre-existing
  expression-layer gap: `ps.mann_whitney_u`/`ps.wilcoxon_signed_rank` struct fields are exactly
  `["p_value", "statistic"]` — estimate/CI remain PyModel-only, unchanged by this retarget.
- Full gate green: `uv run pytest tests/ -q` → 951 passed, 5 pre-existing skips, 0 failed;
  `uv run ruff check tests/test_wilcoxon_mcnemar_parity.py` clean.
