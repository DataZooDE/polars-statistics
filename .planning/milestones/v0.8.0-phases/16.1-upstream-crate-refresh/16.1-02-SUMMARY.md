## Accomplishments

- Added `effect_size_output_dtype`/`effect_size_output` (single-field `struct{estimate: f64}`) and `fisher_output_dtype`/`fisher_output` (`struct{statistic, p_value, ci_lower, ci_upper}`) helpers to `output_types.rs`, mirroring the existing `generic_stats_output` precedent.
- Exposed `ps.cohens_d(x, y, kind="student"|"welch"|"paired", mu)` and `ps.cohens_d_one_sample(x, mu)` end-to-end (Rust `cohens_d_fit`/`pl_cohens_d` + `cohens_d_one_sample_fit`/`pl_cohens_d_one_sample`, Python builders with input validation on `kind`, exports, and a tracer-gated R-reference test suite): all three `kind` values and one-sample match R `effectsize::cohens_d` to 1e-10, including the `mu`-shifted paired case; constant/degenerate samples return NaN (never an exception); works in `group_by`/`.over()`.
- Exposed `ps.rank_biserial(x, y, mu)`, `ps.matched_pairs_rank_biserial(x, y, mu)`, and `ps.rank_biserial_from_u(u1, n1, n2)` (Rust `rank_biserial_fit`/`matched_pairs_rank_biserial_fit`/`rank_biserial_from_u_fit` + `pl_*` shims), cross-checked against `MannWhitneyU.statistic`, documented with the sign-convention note (opposite of R's `effectsize::rank_biserial`), and the O(n1*n2)/O(1) complexity note.
- Wired `conf_level: float = 0.95` through `ps.binom_test`, `ps.prop_test_one`, `ps.prop_test_two`, and `ps.fisher_exact` via the new `anofox_statistics::*_with_conf_level` functions and a tolerant `trailing_conf_level` Rust helper (`inputs.get(idx)`, default 0.95) that keeps previous-arity rlib callers working. Verified the 0.95 defaults are byte-identical to the pre-plan behaviour and that `conf_level=0.9` intervals match R to 1e-8.
- `ps.fisher_exact`'s output struct gained trailing `ci_lower`/`ci_upper` (Woolf/logit interval); `statistic`/`p_value` are unchanged in name, order, and value. Added `ps.fisher_exact_conditional(a, b, c, d, alternative, conf_level)`, exposing R `fisher.test`'s conditional-MLE odds ratio and exact conditional interval (one-sided for one-sided `alternative`), matching R to within the documented `1e-3`/`2e-2` tolerance (root-finding precision difference, not a defect — see upstream docs).
- Full gate green: `cargo clippy --all-targets -- -D warnings`, `cargo fmt --all -- --check`, and `uv run pytest tests/ -q` (772 passed, 5 pre-existing skips, 0 failed — up from 734 passed before this plan).

## Decisions Made

- `fisher_exact`'s schema widening (statistic/p_value -> statistic/p_value/ci_lower/ci_upper) required zero edits to pre-existing tests: they use `"statistic" in fisher` / `"p_value" in fisher` membership checks, which remain true with the two new trailing fields.
- `fisher_exact_conditional` is a separate builder rather than a `fisher_exact` kwarg, since it reports a different odds-ratio estimator (conditional MLE vs sample `ad/bc`) and interval semantics (exact conditional vs Woolf) — conflating them under one name would silently change `fisher_exact`'s existing output for any caller who passed the new option.
- `matched_pairs_rank_biserial`'s unequal-length error branch is unreachable through the Python builder (its joint `is_finite()` filter guarantees equal-length `x`/`y`), so that Rust-contract edge case is tested by calling `register_plugin_function` directly with manually constructed unequal-length `Series`, bypassing the builder.
