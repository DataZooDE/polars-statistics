Upstream behaviour changes since the 16.1 pins (read `CHANGELOG.md` sections [0.5.17]-[0.5.22] of
`~/.cargo/registry/src/*/anofox-regression-0.5.22/` and [0.4.7] of `.../anofox-statistics-0.4.7/` after the bump; at planning
time the same text is in `~/projects/rust/anofox-regression` / `~/projects/rust/anofox-statistics-rs`):
- anofox-statistics 0.4.7: additive only (TestResult, p_adjust, ptukey/qtukey, post-hoc) — no behaviour change expected.
- 0.5.17: penalized GLM only (Poisson dispersion 1 + `estimate_dispersion`, Gamma logLik at deviance/n, R-style null deviance) —
  not yet exposed, so no existing test is affected (Plans 02 / 04 validate it). Also adds the AID heuristic and eb_shrink (16.3).
- 0.5.18: GLMM NegBin / Gamma / Tweedie, offset, per-factor random slopes (16.3); "existing intercept-only crossed fits are unchanged".
- 0.5.19 (#62): LARS / LassoLars alias the later of exactly collinear columns (NaN coefficient) instead of a platform-dependent result.
- 0.5.20 (#66): intercept inference on every GLM — Binomial, Poisson, NegBin, Tweedie, Gamma fill `intercept_t_statistic`,
  `intercept_p_value`, `intercept_conf_interval` and slope CIs; Tweedie / Gamma also report statistics / p-values (t on the residual
  df, summary.glm) that were missing; probit link now uses statrs erfc / erfc_inv (SEs were off R in the 5th digit); GLM Wald p-values
  use the survival function (no underflow to 0). ModelInfo / augment are additive (16.3).
- 0.5.21 (#64, #65): OLS / WLS alias like R lm (dqrdc2, tol 1e-7 relative to each column's norm) for every solver — `svd` no longer
  returns a minimum-norm split, qr / WLS alias the LATER column of a collinear set (`[x1, 2*x1]` aliased column 1 before), the decision
  is scale-independent; WLS-without-intercept SEs come from the reduced fit; LARS fills adj_r_squared / mse / rmse (0.0 placeholders before).
- 0.5.22 (#72, the target; user decision 2026-10-09, verified at planning time by diffing tags v0.5.21..v0.5.22): performance only — warm-started
  `MASS::glm.nb` theta alternation in the penalized GLM (early stop when theta diverges on non-overdispersed data), grouped digamma / trigamma
  sums in `core::estimate_theta_ml` (also used by the existing `NegativeBinomial` class's theta estimation; equal to the per-row sums within
  ~1e-9 relative, only for n of at least 64 with at most n/4 distinct counts), streaming Tweedie log-likelihood; one new low-level pub fn `irls::fit_irls_from`.
  The R fixture and upstream validation test are byte-identical to 0.5.21's; Cargo.toml dependency set unchanged. Watch NegBin theta / SE
  assertions with tight tolerances in the triage; any shift must stay within upstream's stated tolerance.

Where these surface in polars-statistics (verified at planning time): `ps.ols` / `ps.wls` / `ps.*_summary` / `OLS` / `WLS` (solve_method qr /
svd / cholesky); `ps.logistic_summary`, `ps.poisson_summary`, `ps.negative_binomial_summary`, `ps.tweedie_summary`, `ps.probit_summary`,
