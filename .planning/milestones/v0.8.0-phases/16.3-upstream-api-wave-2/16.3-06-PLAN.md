Plan 05 created `crate::pymodels::augment::augment_dict<'py, M: Augmentable + ?Sized>(py, fitted: &M, x, y, weights:
Option<PyReadonlyArray1>, residual_type: Option<&str>) -> PyResult<Bound<'py, PyDict>>`, `ps.augment`, `OLS.augment` and
`WLS.augment`, and `tests/test_augment.py` (with the m1a fixture loader and `rel_close`). Plan 02 added inference getters and
`compute_inference` / `confidence_level` kwargs to these eight classes — leave them untouched.

Fitted types (all implement `anofox_regression::diagnostics::Augmentable`): Poisson → FittedPoisson; Logistic / Probit / Cloglog →
FittedBinomial; LogisticRegression → FittedLogistic; NegativeBinomial → FittedNegativeBinomial; Tweedie → FittedTweedie; Gamma →
FittedGamma. GLMs have no prior weights in this codebase, so the GLM method signature is `(x, y, residual_type=None)` and the helper
receives `weights = None`. Upstream default residual type for GLMs is deviance; NegativeBinomial uses φ = 1 for std residuals / Cook's
distance and the leave-one-out scale for rstudent / dffits (R glm.nb objects).

R references (tests/fixtures/m1a_reference.py; designs and settings as in Plan 05's context): POIS_* on (MT_WT, MT_HP) → MT_CARB;
BIN_* on (MT_MPG,) → MT_VS; GAMMA_* on (MT_WT, MT_HP) → MT_MPG (max_iter 100); NB_* on (WB_WOOLB, WB_TM, WB_TH) → WB_BREAKS;
GLM tolerance 1e-12; comparison rel 1e-6. Upstream checks LogisticRegression leverage against BIN_HAT at 1e-5.

Gates: clippy `-D warnings`, `cargo fmt --check`; tests/test_augment.py full ruff; stubs regenerated after each task.
</context>
