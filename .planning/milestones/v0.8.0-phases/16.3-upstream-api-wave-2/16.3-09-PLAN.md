Source of truth for every documented signature, default and field: the live package (`uv run python -c "import inspect,
polars_statistics as ps; print(inspect.signature(ps.tukey_hsd))"`, and for struct fields the `.schema` of a tiny
`pl.DataFrame(...).select(<expr>)`), not docstrings (project memory: docstrings can understate struct fields).

Facts to state (from Plans 01-08): post-hoc tests take long-format (values, groups); the group column is cast to String and
labels sort as strings; NA / NaN values and null groups are dropped; < 2 groups → empty list; estimate = group2 - group1 (Dunn's
sign is the reverse of dunn.test's printout); Tukey p_value == p_adj (simultaneous); pairwise_t ci_* and Dunn df / ci_* are NaN;
row fields group1, group2, n1, n2, estimate, statistic, df, p_value, p_adj, ci_lower, ci_upper. p_adjust: R methods holm /
hochberg / hommel / bonferroni / BH (fdr) / BY / none, NaN / null kept and excluded from n, whole-column (use `.over`).
ptukey / qtukey: elementwise, broadcast scalars, NaN for invalid parameters. eb_shrink: row-aligned struct {shrunken,
shrunken_se, weight, mu, mu_se, tau_squared, i_squared, q, n_groups}, method dl / none, tau_squared override, I² is
Higgins-Thompson, unusable rows NaN-aligned, `.over(family)`; matches metafor rma(method = "DL") / blup(). augment: models ols /
wls / logistic / probit / cloglog / poisson / negative_binomial / tweedie / gamma, residual_type response / pearson / deviance
(defaults response for ols / wls, deviance otherwise), row-aligned fields fitted / residual / std_residual (rstandard) /
stud_residual (rstudent) / leverage (hatvalues) / cooks_d (cooks.distance) / dffits, NA rows → NaN; PyModel `.augment(x, y[,
weights], residual_type=None)` returns a dict incl. resid_type. alias_tolerance default 1e-7 (R lm), later collinear column aliased
(NaN). LARS adj_r_squared / mse / rmse use df = active coefficients + intercept. model_info dict {model_type, family, link}
(family None for non-likelihood estimators).

Gates: `uv run mkdocs build --strict` must pass; python blocks on the two new pages must execute.
