Upstream API (read-only; `~/projects/rust/anofox-statistics-rs` at tag v0.4.7 = commit 7175dc4; re-exported at the crate root):
- `p_adjust(p: &[f64], method: PAdjustMethod) -> Vec<f64>` — NaN kept and excluded from n. `PAdjustMethod: FromStr` parses
  "holm" | "hochberg" | "hommel" | "bonferroni" | "BH" | "fdr" | "BY" | "none" case-insensitively.
- `ptukey(q, nmeans, df, nranges, lower_tail: bool) -> f64`, `qtukey(p, nmeans, df, nranges, lower_tail) -> f64` — NaN for NaN
  or invalid parameters (df < 2, nranges < 1, nmeans < 2).
- `tukey_hsd<G: Ord + Clone>(values: &[f64], groups: &[G], conf_level: f64) -> Result<PairwiseResult<G>>`;
  `pairwise_t_test(values, groups, pooled_sd: bool, p_adjust_method: PAdjustMethod, alternative: Alternative)`;
  `dunn_test(values, groups, p_adjust_method: PAdjustMethod)`. Errors (`StatError`) for < 2 groups, a NaN value, an invalid
  conf_level.
- `PairwiseComparison<G> { group1, group2, estimate, statistic, df: Option<f64>, p_value, p_adj, conf_low: Option<f64>,
  conf_high: Option<f64> }`; `PairwiseResult<G> { method, p_adjust_method, alternative, conf_level, groups: Vec<G>,
  group_sizes: Vec<usize>, comparisons }`. Tukey: df / conf_* always Some, p_value == p_adj. pairwise_t: df Some, conf_* None.
  Dunn: df / conf_* None; its statistic is the z for group2 - group1 (R's dunn.test reports the opposite sign).
