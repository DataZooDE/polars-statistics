# Phase 16.3 Plan 06: GLM PyModel .augment() Summary

**All eight GLM PyModel classes (Poisson, Logistic, Probit, Cloglog, LogisticRegression, NegativeBinomial, Tweedie, Gamma) now expose `.augment(x, y, residual_type=None)` — R-validated per-observation `broom::augment` diagnostics, delegated through the shared `augment_dict` helper and parity-checked against `ps.augment(..., model=<same model>)`.**

## Accomplishments

- `Poisson.augment`, `Logistic.augment`, `Probit.augment`, `Cloglog.augment`, `LogisticRegression.augment`, `NegativeBinomial.augment`, `Tweedie.augment`, `Gamma.augment` — each a one-line delegation to `crate::pymodels::augment::augment_dict(py, fitted, x, y, None, residual_type.as_deref())` behind `not_fitted_err(<ClassName>)`, identical in shape to the `OLS.augment`/`WLS.augment` methods from 16.3-05.
- Confirmed via the `anofox-regression` 0.5.22 source that `Augmentable::augment_spec()` always reads family/link/theta from the fitted object itself — so every PyModel's `.augment()` automatically describes exactly the model that instance was fit with (the instance's own `link_power`, `var_power`, `theta`), satisfying the cross-plan consistency rule from 16.3-05's post-plan fix by construction, with no reconciliation logic needed.
- R validation (mtcars/warpbreaks m1a fixture, reused verbatim): Poisson deviance + Pearson residuals vs `POIS_*` (rel 1e-6); Logistic deviance + Pearson vs `BIN_*` (rel 1e-6); LogisticRegression vs `BIN_*` at rel 1e-5 (separate sklearn-style solver, looser tolerance per plan); NegativeBinomial and Gamma deviance fields vs `NB_*`/`GAMMA_*` (rel 1e-6); Tweedie(`var_power=2.0`, `link_power=0.0`) reproduces Gamma's Cook's distance and response residual (rel 1e-6).
- Expression parity: every class's `.augment()` output equals `ps.augment(..., model=<same model>)` row-for-row at rel 1e-10 (rel 1e-5 for LogisticRegression, matching its R tolerance); Probit/Cloglog leverage sums to rank (2.0).
- Error handling: every class raises `RuntimeError` naming itself when unfitted; mismatched x/y lengths and unknown `residual_type` raise `ValueError` (inherited from the shared helper).
- Regenerated `.pyi` stub after each task; stub-drift guard clean (10 total `def augment` entries: OLS, WLS, and the eight GLM classes).
- 45 new tests in `tests/test_augment.py::TestGlmPyModelAugment`; full suite 1704 passed, 6 skipped, 0 failed.
