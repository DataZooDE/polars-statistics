Shape decision (Claude's discretion, recorded here and in COVERAGE.md): `eb_shrink` produces one output row per input row
(`returns_scalar=False`), like the `*_predict` expressions, because every shrunken value belongs to an input row; the
whole-sample scalars (mu, mu_se, tau_squared, i_squared, q, n_groups) repeat on each row. `df.with_columns(ps.eb_shrink(
"est", "se").alias("eb")).unnest("eb")` therefore aligns directly with the data, and `.over("family")` shrinks per family.
`ShrunkenGroup.estimate` / `.se` (input echoes) are not output (COVERAGE OPT-OUT).

Upstream (`anofox_regression::solvers::eb_shrink`, also in the prelude; 0.5.22 `src/solvers/eb_shrink.rs`):
`eb_shrink(estimates: &[f64], standard_errors: &[f64], options: &EbShrinkOptions) -> Result<EbShrinkResult, EbShrinkError>`;
`EbShrinkOptions { method: TauMethod (DerSimonianLaird default | None), tau_squared: Option<f64> (overrides method; finite, >= 0) }`
(derives Default); `EbShrinkResult { mu, mu_se, tau_squared, i_squared, q, n_groups: usize, groups: Vec<ShrunkenGroup> }`;
`ShrunkenGroup { estimate, se, shrunken, shrunken_se, weight }` — one per input row in input order; rows with a non-finite
estimate or non-positive / non-finite se are dropped from mu / tau² but kept NaN-aligned. Errors: `EmptyInput`,
`DimensionMismatch`, `InsufficientData { usable }` (< 2 usable rows), `InvalidValue` (bad fixed tau²).
