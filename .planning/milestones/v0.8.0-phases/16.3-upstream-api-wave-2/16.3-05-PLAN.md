and GLMs, inside group_by / over or on a fitted model object.

Shape decision (Claude's discretion, per CONTEXT resolution 5 "one combined expression"): `ps.augment` is row-aligned like the
`*_predict` expressions (`returns_scalar=False`, one struct per input row), because broom::augment adds columns to the data;
the existing piecewise diagnostics (`ps.leverage`, `ps.cooks_distance`, ...) keep their list-per-group shape untouched. The
Python builder resolves the residual-type default explicitly (response for ols / wls, deviance otherwise), so the expression
never needs a resid_type field; the PyModel dict reports `resid_type`.

Upstream (`anofox_regression::diagnostics::{augment, augment_with, Augment, Augmentable, ResidualType}`, 0.5.22
`src/diagnostics/augment.rs`): `augment(&fit, &x, &y, weights: Option<&Col<f64>>) -> Result<Augment, RegressionError>`,
`augment_with(.., resid_type: ResidualType)`; `ResidualType::{Response, Pearson, Deviance}` with `as_str()`; `Augment { fitted,
residual, resid_type, std_residual, stud_residual, leverage, cooks_d, dffits }` (Col<f64>, one entry per row); x / y must be the
training data (length mismatch → Err); weights: prior weights (WLS defaults to the fit's own `weights()`); negative / NaN weight
→ Err; rows with h = 1 → NaN. `Augmentable` is implemented for FittedOls, FittedWls, FittedPoisson, FittedBinomial (so
Logistic, Probit and Cloglog — all store FittedBinomial; this corrects RESEARCH Pitfall 4), FittedLogistic, FittedNegativeBinomial,
FittedTweedie, FittedGamma. It is not a supertrait of FittedRegressor: a `Box<dyn FittedRegressor + Send + Sync>` cannot be
augmented, so py_wls.rs must store `FittedWls` concretely (16.1 Plan 05 may already have done so for `variance_factor`).

R references in tests/fixtures/m1a_reference.py (Plan 02; upstream `tests/r_validation_m1a.rs`): for OLS, WLS, BIN, POIS, GAMMA, NB:
`*_FITTED`, `*_RESID` (OLS / WLS response residual; GLMs `*_RESID_DEV` and `*_RESID_PEAR`), `*_RSTD` (GLMs `*_RSTD_DEV` /
`*_RSTD_PEAR`), `*_RSTUD`, `*_HAT`, `*_COOK`, `*_DFFITS`. Designs: OLS / WLS / Poisson / Gamma on (MT_WT, MT_HP) with y MT_MPG
(Poisson y MT_CARB; WLS weights MT_W); binomial (MT_MPG,) → MT_VS; NB (WB_WOOLB, WB_TM, WB_TH) → WB_BREAKS. GLM fits use
tolerance 1e-12 (Gamma / Tweedie max_iterations 100); tolerance `|a - b| <= tol * max(|b|, 1)`, tol 1e-8 linear / 1e-6 GLM;
the Pearson variants compare residual and std_residual only (rstudent / hat / cooks / dffits are type-independent).
`augment_residual_type_names_and_wrappers`: Tweedie gamma-family Cook's distance == GAMMA_COOK (1e-6) and its response residual
== MT_MPG - GAMMA_FITTED (1e-6).

Existing analog: `pl_negative_binomial` (kwargs struct shim, `#[derive(Deserialize)]`), `prediction_output_with_prefix`
(per-row StructChunked), `build_xy_with_null_policy`, the `ps.leverage` / `ps.cooks_distance` / `ps.dffits` /
`ps.studentized_residuals` / `ps.externally_studentized_residuals` builders (OLS-based, list-per-group outputs).
