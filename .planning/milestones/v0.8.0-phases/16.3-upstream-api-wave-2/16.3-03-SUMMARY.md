## Accomplishments

- `GLMM.negative_binomial(nb_theta=None)`, `GLMM.gamma()`, `GLMM.tweedie(power=1.5)` factories with the log link, matching `glmer.nb`, `glmer(family=MASS::negative.binomial(theta))`, `glmer(Gamma(log))` and `glmer(statmod::tweedie(1.5))` within the upstream scaled tolerance (2e-4, or 2e-3 for the NB-estimated-theta case).
- Per-observation `offset=None` kwarg on `fit`, `fit_crossed` and `predict_fixed`, coefficient fixed at 1, matching `offset()` in an lme4 formula for every family.
- `random_intercept`, `random_slopes`, `random_slopes_per_factor` and `theta_max` builder options on all six factories, routed through one private validating constructor (`PyGLMM::construct`).
- `random_cov`, `random_effects_matrix`, `random_corr`, `n_random_effects`, `n_factors`, `is_reml` getters and `factor_random_cov(f)` / `factor_random_sd(f)` / `factor_random_effects_matrix(f)` methods, each returning `None` for a single-factor fit or an out-of-range factor index.
- `tests/fixtures/glmm_families_reference.py`: verbatim Python transcription of upstream's `glmm_families_validation.rs` (82 constants, `SOURCE_SHA256 = 7db4c5ddd80c0ff26818aa9b50ea6f76e3a3db2c3c1c92d916ffbdb95162e76c`), with a live re-parse-and-compare integrity test against the cargo registry checkout.
