<decisions>
## Implementation Decisions

### User instruction
"add these new functionality and update everything that is necessary"; on 2026-10-09 the user chose "bump now, new API → 16.3", shipping in 0.8.0. Full API coverage; opt-outs only with a written reason in COVERAGE.md.

### Orchestrator resolutions of the research open questions (research recommendations)
1. **`TestResult`: opt out.** Every test class already has `to_dict()` / `summary()` via `ergonomics.rs`, so a second unified shape is redundant. Record the cheap reversal path (`.to_test_result()` per class through the upstream `From` impls) in COVERAGE.md.
2. **AID heuristic (`compute_aid` / `compute_aid_anomalies`): opt out.** It is redundant with the richer existing `Aid` / `AidClassifier` PyModel, and upstream says it complements rather than replaces it. Record the reason.
3. **Slope / intercept CIs for OLS/WLS/GLMs: PyModel getters only.** The shared 5-field `summary_output_dtype` is NOT widened. Add the intercept inference getters (`intercept_std_error`, `intercept_t_statistic` / z, `intercept_p_value`, `intercept_conf_interval`, `conf_interval_lower` / `upper`) to all GLM PyModels that lack them.
4. **`ModelInfo`: full rollout.** A `model_info` getter (model_type, family, link) on every fitted PyModel whose upstream type implements `HasModelInfo`, as its own plan.
5. **`augment`: one combined expression plus a PyModel method** on the supported models (OLS, WLS, Poisson, binomial/logistic, NegBin, Tweedie, Gamma). `residual_type` selects deviance or Pearson. Add a numeric cross-check against the existing influence diagnostics.
- **Post-hoc tests** (`tukey_hsd`, `pairwise_t_test`, `dunn_test`) are long-format `(values, groups)` expressions returning a List<Struct> of pairwise rows. The group column is cast to Utf8. Expression-only, no new PyO3 classes (16.1 precedent).
- **`p_adjust`, `ptukey`, `qtukey`** are elementwise expressions (bare Float64 output, `returns_scalar=False`).
- **`eb_shrink`** is expression-only over estimate / SE columns.
- **GLMM**: NegBin / Gamma / Tweedie families, `nb_theta`, `offset`, `predict_fixed_with_offset`, `random_slopes_per_factor`, and the per-factor covariance / SD / BLUP accessors, added additively to the existing GLMM PyModel (and to its expressions, if those exist).
- **OLS/WLS `alias_tolerance`** as a constructor/kwarg option.
- **Additive only**: no reshaping of existing output structs or signatures.
- **Validation**: R references from the upstream tests (TukeyHSD, pairwise.t.test, dunn.test, p.adjust, ptukey/qtukey, broom::augment, lme4, metafor).
- **Docs**: stubs, docstrings, mkdocs, CHANGELOG `[Unreleased]` (shared), skills + harness. No version bump (Phase 17). Do not create `python/polars_statistics/_plugin/`.

</decisions>
