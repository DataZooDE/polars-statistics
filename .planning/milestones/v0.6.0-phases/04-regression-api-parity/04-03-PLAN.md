| Python → PyO3 (`hc_inference`) | User design matrix X re-supplied at inference time; may mismatch fitted model |

| T-04-07 | Information Disclosure | HC SEs computed with X mismatched to fitted coefficients | low | mitigate | `compute_hc_inference` returns `Err` on dimension mismatch; mapped to `PyValueError` |
