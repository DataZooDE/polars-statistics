# Phase 9 — Result Ergonomics (Plan 09-01)

**Milestone:** v0.7.0 — Ergonomics, Adoption & Documentation
**Branch:** `phase-9-result-ergonomics`
**Requirements:** ERGO-01, ERGO-02, ERGO-03

## Goal

Make the existing statistical result surface best-in-class to consume:

- **ERGO-01** — one-call conversion of any result to a Python `dict`, for both
  fitted model/test classes and Polars Struct result columns.
- **ERGO-02** — a readable `.summary()` and an informative `__repr__` on every
  model/test class, never panicking on unfitted state.
- **ERGO-03** — a documented helper that unnests a result Struct column into flat
  DataFrame columns in one call.

## Design decisions

1. **DRY via runtime introspection, not 42× copy-paste.** A shared Rust module
   `src/pymodels/ergonomics.rs` provides three generic free functions that take
   the object as `&Bound<PyAny>` and introspect its own `#[getter]` properties
   (detected as `getset_descriptor` in the type's MRO):
   - `repr(slf)` → `Class(fitted=True, r_squared=…, …)` (headline scalar fields,
     capped; `Class(fitted=False)` when unfitted).
   - `to_dict(slf)` → dict of every resolvable getter; `{"fitted": False}` for
     unfitted models (chosen over raising so callers branch without try/except).
   - `generic_summary(slf)` → readable multi-line `name: value` listing.

   PyO3's `#[pymethods]` proc-macro cannot expand declarative macro calls as
   items, so each class delegates via three tiny methods (`__repr__`, `to_dict`,
   and `summary` where no bespoke one exists) that call the shared functions.
   Insertion was automated by a one-shot script (brace-matched, idempotent),
   preserving the 12 existing bespoke `summary` implementations.

2. **Expression Struct-column surface** (ERGO-01 for expressions + ERGO-03):
   a pure-Python module `python/polars_statistics/results.py` exposing
   `ps.unnest(df, column=None, *, prefix=None, keep_others=True)` and
   `ps.struct_to_dict(df, column=None)` (single dict for 1 row, list[dict] for
   many). Auto-resolves the target when there is exactly one Struct column.

3. **Stub drift + typing.** Regenerate `_polars_statistics.pyi` via
   `scripts/gen_stubs.py` (add fully-qualified `PyDict` → `dict` mapping so
   `to_dict` types as `dict`). `results.py` is fully annotated and added to the
   CI `Type Stubs` mypy invocation.
