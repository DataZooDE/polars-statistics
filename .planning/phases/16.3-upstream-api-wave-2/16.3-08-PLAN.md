<objective>
Roll out anofox-regression 0.5.20's `ModelInfo` (model type, error family, link) as a `model_info` getter on every fitted
PyModel whose upstream type implements `HasModelInfo` — the full 30-class rollout, as its own plan (UPST-09, ROADMAP 16.3
criterion 2, CONTEXT resolution 4).

Purpose: generic tooling (reporting, serialisation, model comparison) can label any fitted model without isinstance chains.
Output: a shared helper, 30 getters, stubs, a parametrized test.

File-count note: tasks 2 and 3 each touch more than five files. This is deliberate: CONTEXT resolution 4 requires the rollout
to be a single dedicated plan, and every file receives the same ~8-line getter delegating to one helper (per-file context cost:
one grep for the fit / getter anchors plus one edit), so the split would add plans without reducing per-edit risk.
</objective>
