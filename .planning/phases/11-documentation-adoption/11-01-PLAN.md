Make the v0.6.0 API surface — plus the ergonomics/typing/consistency work from
phases 8-10 — best-in-class to adopt. Ship runnable cookbook pages, worked
examples, decision aids, and migration guides. **Docs + runnable examples only —
no Rust changes, no `.py` changes under `python/polars_statistics/`.**

## Approach

1. Build the extension (`.venv/bin/maturin develop`) so example scripts run against
   the real API.
2. Read `_polars_statistics.pyi` for exact class signatures; verify every getter /
   method / kwarg against reality before documenting it.
3. Write each example script first, run it to exit 0, then lift its verified output
   into the cookbook page (so every snippet is grounded in real output).
4. Write the guides (model-selection, migration, sklearn-migration) and refresh the
   README.
5. Update `mkdocs.yml` nav; cross-link the icc note.

## Verification gates

- Each new `examples/*.py` runs to exit 0 under `.venv/bin/python`.
- `.venv/bin/ruff check` clean on the new scripts.
- `.venv/bin/mkdocs build --strict` passes.
- `.venv/bin/python -m pytest tests/ -q` stays green (no regressions).
- No `.py` touched under `python/polars_statistics/` → stub drift guard satisfied.

- Version bumps (Phase 12 / REL-05).
- PyPI publish (Phase 12 / REL-06).
