# Phase 16.2 Plan 05: AFT Survival Regression Summary

**`AFT` PyO3 class + `ps.aft`/`ps.aft_summary`/four `ps.aft_predict_*`/`ps.aft_formula`/`ps.aft_formula_summary` expose anofox-regression 0.5.22's accelerated failure time engine (Weibull, log-normal, log-logistic, exponential, right censoring), validated coefficient-for-coefficient against `survival::survreg` on both the PyModel and expression layers.**

## Performance

- **Duration:** ~2h 10min
- **Tasks:** 3
- **Files modified:** 12 (3 new, 9 modified)

## Accomplishments

- `src/expressions/aft.rs` (new): `AftKwargs` serde struct threading every AFT option (distribution, priors, vcov_type, with_intercept, max_iter, tol, conf_level, prefix, p, t, null_policy) so no option can be silently dropped or index-mismatched; `parse_aft_distribution` (upstream `AftDistribution::from_name` aliases), `build_aft`, `aft_inputs` (event-coding dispatch by dtype, null-event-masks-time semantics); the 12-field `aft` output struct and `pl_aft`; `aft_summary_fit`/`pl_aft_summary` (7-field tidy summary with the intercept row read directly from upstream's `AftInference` and the `log_scale` row via `log_scale_wald`); `aft_predict_impl` shared by the four `aft_predict_{quantile,median,survival,cdf}_fit`/`pl_aft_predict_*` pairs.
- `src/pymodels/py_aft.rs` (new): `AFT` PyO3 class — constructor validates distribution/vcov_type/max_iter/tol/confidence_level at construction; `fit(x, time, event)` accepts `event` as bool/int/float arrays or lists and rejects any value other than 0/1 with `ValueError`; `predict_linear`/`predict_quantile`/`predict_median`/`predict_survival`/`predict_cdf`; every meaningful upstream accessor including the 0.5.20 `intercept_std_error`/`intercept_z_value`/`intercept_p_value`/`intercept_conf_interval` fields (read directly from `AftInference`, never recomputed), `log_scale_std_error`, scaled `vcov`/`information`, and ergonomics (`__repr__`/`to_dict`/`summary`).
- `python/polars_statistics/exprs/regression.py`: `aft`, `aft_summary`, `aft_predict_quantile`/`_median`/`_survival`/`_cdf`, `aft_formula`, `aft_formula_summary` builders with Python-side validation mirroring the Rust parser exactly, so invalid configuration raises `ValueError` at expression-build time, before `.collect()`.
- `tests/test_aft.py` (new, 42 tests across both layers): Weibull end-to-end via the expression path, struct schema, event-coding variants and failure modes (invalid value, time<=0, all-censored, null time/event); all four distributions on the PyModel vs the R fixture (coefficients/scale/log-likelihoods/SEs/upstream intercept inference/quantiles), event-array-type equivalence, vcov/information shape and identity, priors shrinkage and vcov_type divergence, dict/tuple prior equivalence, build/fit-time `ValueError`s, unfitted `RuntimeError`s, ergonomics; `ps.aft_summary` terms/SEs/upstream-equal-inference/`conf_level` half-width for all four distributions; the four predict expressions vs `survreg` at a held-out row under `drop_y_zero_x` vs NaN under the default `drop` policy, default/custom prefixes, in-sample PyModel parity; `group_by`/`.over` equivalence; `aft_formula`/`aft_formula_summary` equal the column forms.
- `tests/rust_api.rs`: new `aft_*_fit` smoke block with `AftKwargs`, including an `Err` (no panic) assertion for an invalid distribution.
- Full `uv run pytest tests/ -q`: **1281 passed, 6 skipped, 0 failed** (unchanged skip count from Plan 04; +42 from this plan). `cargo test --no-default-features --lib -q` and `--test rust_api -q`: green (the new `log_scale_wald` unit test and 18 rlib smoke tests respectively).
