# Phase 16.2 Plan 02: Penalized GLM Engine Summary

**`PenalizedGLM` PyO3 class + `ps.penalized_glm`/`ps.penalized_glm_formula` Polars expressions expose anofox-regression 0.5.22's family-generic penalized GLM engine (6 families, Gaussian/Laplace priors, 3 covariance types, offset, Poisson quasi-dispersion), validated coefficient-for-coefficient against the upstream R fixture on both layers.**

## Performance

- **Duration:** ~50 min
- **Tasks:** 3
- **Files modified:** 13 (4 new, 9 modified)

## Accomplishments

- `src/expressions/penalized_glm.rs` (new): `PriorKwarg`/`PenalizedGlmKwargs` serde structs, `parse_penalized_glm_family`/`prior_spec_from_parts`/`parse_vcov_type`/`build_penalized_glm` shared helpers, the 15-field `penalized_glm` output struct, and the `pl_penalized_glm` plugin shim — one named kwargs struct threads every option so none can be silently dropped (T-16.2-03).
- `src/pymodels/py_penalized_glm.rs` (new): `PenalizedGLM` PyO3 class with `fit`/`predict`/`predict_linear` and every meaningful upstream accessor, including the 0.5.20 `intercept_std_error`/`intercept_z_value`/`intercept_p_value`/`intercept_conf_interval` fields read directly from `GlmInferenceResult` (never recomputed), and a `vcov` getter scaled so its diagonal square roots equal the reported standard errors.
- `python/polars_statistics/exprs/regression.py`: `ps.penalized_glm` / `ps.penalized_glm_formula` builders with Python-side validation mirroring the Rust parser exactly, so invalid configuration raises `ValueError` at expression-build time, before `.collect()`.
- `tests/fixtures/penalized_glm_aft_reference.py` (new): verbatim Python transcription of the 0.5.22 upstream R fixture (all 90 constants, including the AFT ones reserved for Plan 05), with `SOURCE_SHA256` recorded and an integrity test that re-parses the upstream crate file byte-for-byte when present on disk.
- `tests/test_penalized_glm.py` (new, 115 tests across both layers): every family/link combination, offset handling, no-intercept null deviance, Gamma log-likelihood at deviance/n, overdispersed-Poisson/quasipoisson dispersion, Negative Binomial (estimated and fixed theta), Gaussian priors across all three covariance types (+ tuple/dict/list equivalence), the documented ridge-lambda-equals-Gaussian-prior relation (confirmed numerically exact), Laplace-prior proximal soft-thresholding (confirmed exact), vcov/information scaling, expression↔PyModel parity, `group_by`/`.over`, the formula wrapper, and build-time `ValueError`/engine-data-error handling.
