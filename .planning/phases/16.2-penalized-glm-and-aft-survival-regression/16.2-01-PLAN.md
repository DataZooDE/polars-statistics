<objective>
Expose anofox-regression 0.5.16's family-generic penalized GLM engine (`solvers::penalized_glm`) as one
Python model class `PenalizedGLM` and one Polars fit expression `ps.penalized_glm`, validated against the R
references that ship inside the crate.

Purpose: UPST-05 (engine + fit surface). Plan 03 adds the summary / predict expressions and the remaining formula
variants on top of the helpers created here; Plan 04 reuses the prior parsing, Wald helper and fixture module for AFT.
Output: one new Rust expression module, one new PyO3 class, Python builder + formula wrapper + exports, regenerated
stubs, a Python transcription of the upstream R fixture, and a test file.

Decisions this plan implements (CONTEXT `<decisions>`, recorded without D-IDs):
- CONTEXT resolution 1: ONE class per engine — `PenalizedGLM(family=..., link=...)`, not one class per family.
- CONTEXT "Builder entry points": use `PenalizedGlmRegressor::builder()...build().fit(&x, &y)`; never the column-major `fit_*`.
- CONTEXT "Priors": plain Python data (tuples or dicts), no new Python classes; priors travel through the expression `kwargs` channel.
- CONTEXT "offset defaults to a pl.lit(0.0) column".
- CONTEXT "Pattern consistency": PyModel in src/pymodels, `#[polars_expr]` fit in src/expressions, Python builder in exprs/regression.py, `.pyi` stubs, `__init__.py` exports, formula interface.
- Claude's discretion (documented here): every scalar configuration value (family, link, theta, power, threshold, lambda, priors, vcov_type, with_intercept, max_iter, tol, conf_level, prefix, predict_type, null_policy) travels in ONE named serde kwargs struct `PenalizedGlmKwargs`; `args` carry only per-row data `[y, offset, *x]`. Rationale: named keys cannot index-slip (16.1 RESEARCH Pitfall 2), rlib callers get `Default`, and the summary/predict expressions of Plan 03 reuse the same struct. New APIs take only `add_intercept: bool = True` (no deprecated `with_intercept` alias on brand-new functions/classes).
- Claude's discretion: the expression module lives in a new file `src/expressions/penalized_glm.rs` (like tost.rs / resampling.rs own their files) instead of growing the 5,700-line regression.rs.
</objective>
