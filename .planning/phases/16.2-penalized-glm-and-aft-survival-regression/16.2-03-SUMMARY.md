## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed `test_mann_whitney_u_expression_nonfinite_matches_filtered_columns` dict-equality assertion broken by the widened struct's NaN fields**
- **Found during:** Task 2 (full-suite audit run)
- **Issue:** The test asserts `result_raw == result_filtered` on two expression-call results. Both results now carry `estimate`/`ci_lower`/`ci_upper` which are NaN in this test's scenario (no `conf_level` requested). Python's `==` on dicts compares values with `==`, and `nan != nan`, so the previously-passing assertion failed the moment the struct gained these fields — even though both sides are identically NaN.
- **Fix:** Changed the assertion to `assert result_raw == pytest.approx(result_filtered, nan_ok=True)`, which compares numeric dict values with NaN treated as equal to NaN.
- **Files modified:** `tests/test_nonfinite.py`
- **Verification:** `uv run pytest tests/test_nonfinite.py::test_mann_whitney_u_expression_nonfinite_matches_filtered_columns -q` passes; full suite green afterward.
- **Committed in:** `bb06812` (Task 2 commit)
