**Gathered:** 2026-10-08

<domain>
## Phase Boundary

Expose the two model families that anofox-regression 0.5.16 added, `solvers::penalized_glm` and `solvers::aft`, through the Polars expression API and the Python model classes. Also close the expression-output gap found while planning 16.1: `ps.mann_whitney_u` / `ps.wilcoxon_signed_rank` accept `conf_level` but return only `{statistic, p_value}`.

</domain>

<decisions>
## Implementation Decisions

### User instruction
"add these new functionality and update everything that is necessary." The user chose to target the latest crates (0.4.6 / 0.5.16) and to cover penalized GLM + AFT in this phase, shipping in 0.8.0.

### Scope
- **Full coverage.** Every public builder option and fitted accessor of `PenalizedGlmRegressor` / `FittedPenalizedGlm` and `AftRegressor` / `FittedAft` that is meaningful from Python is exposed. Anything left out is recorded with a reason in COVERAGE.md.
- **Pattern consistency.** Follow the existing GLM wiring: PyModel classes in `src/pymodels/`, `#[polars_expr]` fit/summary/predict expressions in `src/expressions/`, output dtypes in `output_types.rs`, Python builders in `python/polars_statistics/exprs/`, `.pyi` stubs, `__init__.py` exports, and the formula interface if the existing GLMs support it.
- **Priors.** Expose `PriorSpec` (flat / normal(loc, scale) / laplace(loc, scale), with an optional leading intercept entry) as plain Python data (e.g. a list of tuples or dicts). No new Python classes unless an existing pattern calls for them.
- **AFT inputs.** AFT needs `time` + `event` (right-censoring indicator) columns. Expressions take them as explicit columns, in the way existing multi-input expressions do.
- **Mann-Whitney / Wilcoxon expressions.** Add trailing `estimate`, `ci_lower`, `ci_upper` fields (additive only; existing fields keep their order).
- **Additive only.** No reshaping of existing output structs or signatures.
- **Validation.** Use upstream's R references (`tests/r_validation_penalized_glm_aft.rs`, `tests/r_scripts/penalized_glm_aft_reference.R` in anofox-regression 0.5.16) as pytest fixtures.
- **Docs.** `.pyi` stubs, docstrings, mkdocs pages, the CHANGELOG `[Unreleased]` section (shared with 16.1), and the regression / hypothesis-tests skill cheat-sheets plus the skill-example harness.
- **Research open questions, resolved by the orchestrator using the research recommendations:**
  1. One PyModel class per engine: `PenalizedGLM(family=..., link=...)` and `AFT(distribution=...)`, not one class per family.
  2. AFT prediction: four separate expressions (quantile / median / survival / cdf), consistent with the existing per-purpose predict expressions.
  3. Full `vcov` / information matrices are exposed on the PyModel only; expressions return a new 7-field summary dtype (with `ci_lower` / `ci_upper`). The shared `summary_output_dtype` stays untouched.
  - Builder entry points (not the column-major `fit_*`); priors and `vcov_type` go through `kwargs`; offset defaults to a `pl.lit(0.0)` column.
  - The 16.1 Plan 09 schema-lock test on the Mann-Whitney / Wilcoxon expressions must be updated in this phase when the trailing fields are added.
- **No package version bump** (Phase 17). Do not create `python/polars_statistics/_plugin/` (Phase 16 runs after 16.2).

</decisions>
