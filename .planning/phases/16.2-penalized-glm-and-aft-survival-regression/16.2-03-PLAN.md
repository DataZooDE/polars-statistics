From Plan 01 (read the code, not just the SUMMARY): `PenalizedGlmKwargs` already carries `vcov_type`, `conf_level`,
`prefix`, `predict_type`, `null_policy` with defaults; `build_penalized_glm(kwargs, compute_inference, offset)`,
`wald_inference`, `penalized_glm_intercept_se`, `penalized_glm_covariance_scale`, the null→NaN column helpers and the
offset broadcast rule exist; Python `_normalize_priors` / `_penalized_glm_kwargs` exist.

Summary semantics: rows are `intercept` (when fitted) then `x1..xp` (`build_term_names`). Feature rows take std_error / z /
p / ci from `fitted.inference()` vectors (already scaled); the intercept row uses `penalized_glm_intercept_se` and
`wald_inference(intercept, se, conf_level)` — the same formula upstream applies to the features. Aliased columns
give NaN rows; an inactive Laplace-prior coefficient gives NaN inference. `statistic` is the Wald z (normal
reference), as upstream reports it; R's summary.glm uses t for estimated-dispersion families (Gamma / Tweedie) —
document this in the docstring.

Predict semantics: refit per group with the same options (like every existing *_predict), then predict on all rows.
Reuse `build_xy_with_null_policy(inputs, 0, 2, null_policy)` (y at 0, offset at 1, x from 2) on an input vector where y
is set to null on rows whose offset is null; offset for the fit = offset at the rows the returned valid_mask marks;
prediction offset = all rows (null → NaN → NaN prediction). "drop": rows with any null in y / x / offset predict NaN;
"drop_y_zero_x": null-y rows are excluded from the fit but predicted, x nulls zero-filled. type "response" →
`predict_with_offset(x_pred, offset_pred)`; "link" → `predict_linear(x_pred) + offset_pred`. lower / upper are NaN
(FittedPenalizedGlm has no predict_with_interval — COVERAGE OPT-OUT).

Gates: clippy `-D warnings`, fmt; modified Python files `uv run ruff check --select F,E9`; the new test code lives in
tests/test_penalized_glm.py (full `uv run ruff check`). The first `cargo test --no-default-features --test rust_api`
compile builds polars without Python and can take several minutes — expected.
</context>
