Upstream API (`~/.cargo/registry/src/*/anofox-regression-0.5.16/src/solvers/aft/`, verified at planning time):
- Imports: `anofox_regression::solvers::aft::{AftRegressor, AftDistribution, FittedAft}`.
- `AftDistribution::{Weibull, LogNormal, LogLogistic, Exponential}`; `from_name(&str)` accepts case-insensitive "weibull", "lognormal" /
  "log_normal" / "log-normal", "loglogistic" / "log_logistic" / "log-logistic", "exponential" / "exp"; `scale_is_fixed()` true only for Exponential.
- Builder (regressor.rs): `.distribution`, `.with_intercept`, `.max_iterations(u32)`, `.tolerance(f64)` (default 1e-9), `.compute_inference`,
  `.confidence_level`, `.priors(Vec<PriorSpec>)`, `.vcov_type(VcovType)`; NO offset. `fit(&Mat<f64>, time: &Col<f64>, event: &[bool])`.
  Upstream (model.rs fit_aft ~143-200) drops rows with a non-finite time or x, errors on time <= 0, on all-censored data and when n < n_params + 1.
- FittedAft: coefficients() (log-time scale), intercept(), scale(), distribution(), log_likelihood(), null_log_likelihood(), aic(), bic(),
  converged(), fit_result() -> &AftFitResult {n_observations, n_events, n_censored, n_features, iterations, ...}, inference() ->
  Option<&AftInference {std_errors, z_values, p_values, ci_lower, ci_upper (feature-only), confidence_level, intercept_std_error: Option,
  log_scale_std_error: Option (None for Exponential), vcov: Option<Mat> (order: intercept, features, log sigma), information: Option<Mat>}>,
  predict_linear, predict_quantile(x, p), predict_median(x), predict_survival(x, t), predict_cdf(x, t).
- AFT inference uses covariance scale 1.0, so `vcov` is consistent with the reported SEs (no scaling needed, unlike PenalizedGLM).
- R fixture constants (tests/fixtures/penalized_glm_aft_reference.py from Plan 01): TIME, EVENT (60), X1, X2; AFT_{WEIBULL,LOGNORMAL,LOGLOGISTIC,EXPONENTIAL}_
  COEF [b0, b1, b2], _SCALE, _LL [null, model], _SE [b0, b1, b2, log(scale)] (3 entries for exponential), _Q [p=0.25, 0.5, 0.9] at x0 = [0.3, -0.2].
  Upstream test `aft_check` uses the default tolerance (1e-9) and compute_inference true; thresholds coef / scale 1e-6, log-lik 1e-7, SE 1e-5,
  quantiles 1e-6, S(q) identity 1e-9.

Design (mirrors Plans 01 / 03; Claude's discretion documented): all configuration in one serde struct `AftKwargs`; `args` carry only per-row data
`[time, event, *x]`. Event handling in Rust: a Boolean column is used as-is; a numeric column must contain only 0 / 1 (anything else → the
NaN struct / NaN predictions, matching upstream's InvalidValue convention); a null event marks the row invalid (its time is masked to null so
upstream drops it). AFT summary rows: intercept (estimate intercept, se intercept_std_error), features (inference vectors), then "log_scale"
(estimate ln(scale), se log_scale_std_error) when the scale is estimated; intercept and log_scale z / p / ci come from `wald_inference` (same
formula upstream uses). Predict expressions refit per group and predict all rows using `build_xy_with_null_policy(masked_inputs, 0, 2,
null_policy)` with time at 0 (null where event is null), event gathered for the rows the valid_mask marks; lower / upper NaN. Default prefixes:
"aft_quantile", "aft_median", "aft_survival", "aft_cdf". New APIs take only `add_intercept: bool = True`.

Gates: clippy / fmt; new Python test file full `uv run ruff check`; modified Python files `--select F,E9`.
