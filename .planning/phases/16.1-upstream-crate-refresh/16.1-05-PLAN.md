Upstream API (anofox-regression 0.5.15; source in `~/.cargo/registry/src/*/anofox-regression-0.5.15/src/`):
- `HuberRegressorBuilder::compute_inference(bool)` / `confidence_level(f64)` (default false / 0.95); covariance is
  MASS `summary.rlm(method = "XtX")`; the L2 `alpha` is not part of it.
- `RansacRegressorBuilder::compute_inference(bool)` / `confidence_level(f64)`; `FittedRansac::inlier_fit() -> &FittedOls`
  (FittedOls derives Clone). Since 0.5.14 the RANSAC `result()` statistics are those of the inlier OLS fit,
  `n_observations` is the inlier count; residuals/fitted values cover all rows; inference is optimistic (ignores the
  inlier selection).
- `TheilSenRegressorBuilder::univariate_pairwise(bool)` (default true).
- `FittedOls::variance_factor() -> Option<Mat<f64>>`, `FittedWls::variance_factor() -> Option<Mat<f64>>`,
  `FittedRidge::variance_factor() -> Option<&Mat<f64>>`; each `leverage_new(&Mat<f64>) -> Col<f64>`. Dimension p+1 with an
  intercept (index 0 = intercept), p without; aliased rows/cols zero; None for fits from moments.
- `RegressionResult` inference fields (all `Option`): `std_errors`, `t_statistics`, `p_values`, `conf_interval_lower`,
  `conf_interval_upper` (Col<f64>), `intercept_std_error`, `intercept_t_statistic`, `intercept_p_value` (f64),
  `intercept_conf_interval` (Option<(f64, f64)>). For Ridge with lambda > 0, t/p/CI are None and std_errors are sandwich SEs.
Existing getter analog: src/pymodels/py_ols.rs `std_errors` / `t_statistics` / `p_values` (Option<Bound<PyArray1>>,
`.as_ref().map(|c| c.into_numpy(py))`). Conversions: `IntoNumpy` for `&Col<f64>` and `&Mat<f64>` in src/utils/array_conversion.rs.
Getters are auto-included by the ergonomics `to_dict` / `summary` introspection; zero-argument computations that return
matrices (`variance_factor`) are methods so `to_dict` stays scalar/vector-shaped.

Ruff: new Python files pass full `uv run ruff check`; modified files pass `uv run ruff check --select F,E9`.
