## Accomplishments

- **Jarque-Bera** (Task 1, tracer): added `jarque_bera_output_dtype`/`jarque_bera_output` (`struct{statistic, p_value, skewness, kurtosis, n: UInt32}`) to `output_types.rs`; `jarque_bera_fit`/`pl_jarque_bera` in `distributional.rs` wrapping `anofox_statistics::jarque_bera`; `ps.jarque_bera(x)` Python builder mirroring `shapiro_wilk`'s non-finite filter; exported in both `__init__.py` files. Validated against R `tseries::jarque.bera.test` (statistic `6.1833442919626558`, p-value `0.045425932072353667`, skewness `1.6519836946632753`, excess kurtosis `1.980864909825267`, n=10) to the exact doctest tolerances; fewer-than-3-values and constant-data inputs degrade to an all-NaN struct with `n == 0`; confirmed scale-invariant and consistent per-group in `group_by`.
- **Bootstrap CIs** (Task 2): added `bootstrap_ci_output_dtype`/`bootstrap_ci_output` (`struct{estimate, se, ci_lower, ci_upper, conf_level, n_bootstrap: UInt32}`); new `src/expressions/resampling.rs` module (registered in `mod.rs`) with `bootstrap_mean_ci_fit`/`pl_bootstrap_mean_ci` (wraps `anofox_statistics::bootstrap_mean_ci`, `block_length` selecting IID/stationary/circular-block resampling) and `bootstrap_ci_fit`/`pl_bootstrap_ci` (fixed `"mean"|"median"|"std"` dispatch to native Rust closures — a deliberate scope limit per the phase's threat model, since the upstream generic closure cannot cross the Python FFI boundary without a GIL-reentrancy hazard). The `"mean"` arm reuses upstream's own mean closure expression verbatim, proven bit-identical to `bootstrap_mean_ci(block_length=0)` for the same seed. New `python/polars_statistics/exprs/resampling.py` module with `bootstrap_mean_ci`/`bootstrap_ci` builders (PEP 604 annotations, nullable `UInt64` seed literal, `ValueError` on an unknown statistic); exported in both `__init__.py` files. Reproducibility, block-length effect, median/std vs. numpy, and all invalid-parameter NaN-degradation paths all verified.
- **rlib smoke tests** (Task 3): new `effect_size_and_resampling_fits()` test in `tests/rust_api.rs` covers `cohens_d_fit` (student/welch/paired, Student estimate pinned to `-2.606655378290357`), `cohens_d_one_sample_fit`, `rank_biserial_fit` (pinned to `0.925`), `matched_pairs_rank_biserial_fit`, `rank_biserial_from_u_fit`, `jarque_bera_fit`, `bootstrap_mean_ci_fit`, `bootstrap_ci_fit`, and `fisher_exact_conditional_fit`. `categorical_fits()` extended so `binom_test_fit`/`prop_test_one_fit`/`prop_test_two_fit`/`fisher_exact_fit` are each called at both the previous arity (proving the tolerant trailing-`conf_level` read) and the new arity; `fisher_exact_fit`'s output struct is asserted to have exactly 4 fields.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] bootstrap_mean_ci/bootstrap_ci Python builders failed on int64 columns**
- **Found during:** Task 2's first pytest run (`test_jarque_bera_bootstrap.py::TestBootstrapMeanCi`)
- **Issue:** `polars.exceptions.ComputeError: invalid series dtype: expected Float64, got i64` — the new test fixture `BOOT_X = list(range(1, 11))` produces an int64 Polars column, and the plugin's `inputs[0].f64()?` call requires Float64; the non-finite filter alone does not coerce dtype.
- **Fix:** Added `x = x.cast(pl.Float64)` immediately after string-to-expr resolution in both `bootstrap_mean_ci` and `bootstrap_ci`, before the `is_finite()` filter — matching the existing cast-before-filter pattern in `exprs/modern.py`'s `energy_distance`.
- **Files modified:** `python/polars_statistics/exprs/resampling.py`
- **Verification:** `uv run pytest tests/test_jarque_bera_bootstrap.py -q -k bootstrap` → 21 passed
- **Committed in:** `58ca440` (Task 2 commit)
