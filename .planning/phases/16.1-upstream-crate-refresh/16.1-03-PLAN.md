<objective>
Expose the three anofox-regression 0.5.14/0.5.15 options that live on GLM-family / recursive /
mixed models: NegBin `estimate_dispersion` (+ the `dispersion` field), RLS `initial_p_diagonal`
(+ its accessor), and GLMM Wald inference (`z_values`, `p_values`, `conf_int`).

Purpose: Implements these COVERAGE.md rows of UPST-03. NegBin and RLS already have expression
families, so the new options land on every existing NegBin/RLS expression (fit, summary, predict,
formula) and on the PyModel; GLMM is PyModel-only (no expression family exists — CONTEXT: do not
invent one).
Output: updated PyModels, kwargs-based expression wiring, Python builders, rlib smoke tests,
regenerated stubs, new tests.

Design (honours CONTEXT "Schema changes: additive only"): the existing positional-scalar inputs
have the variadic x-column tail last, so inserting a new scalar would shift every public
`negative_binomial_*_fit` / `rls_*_fit` input index and break downstream Rust (rlib) callers.
Instead the new options travel as NAMED serde kwargs — the pattern the `*_predict` shims already
use with `PredictKwargs` — and each existing `*_fit` keeps its exact signature and behaviour by
delegating to a new additive `*_fit_with(...)` with default options. `PredictKwargs` itself is NOT
modified (rlib callers build it with a struct literal; adding a field would break them). Named
kwargs also remove the silent index-slip hazard (RESEARCH Pitfall 2).
</objective>
