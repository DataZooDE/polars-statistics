Upstream API (anofox-statistics 0.4.4, crate root; source in `~/.cargo/registry/src/*/anofox-statistics-0.4.4/src/`):
- `jarque_bera(data: &[f64]) -> Result<JarqueBeraResult>`; `JarqueBeraResult { statistic, p_value, skewness, kurtosis, n: usize }`
  (population moments, excess kurtosis; errors: n < 3, non-finite, zero variance).
- `bootstrap_mean_ci(data, n_bootstrap: usize, conf_level: f64, block_length: usize, seed: Option<u64>) -> Result<BootstrapCIResult>`
  (block_length 0 = IID, 1 = StationaryBootstrap(expected block 1), >1 = CircularBlockBootstrap(block_length)).
- `bootstrap_ci<F: Fn(&[f64]) -> f64>(data, statistic: F, n_bootstrap, conf_level, seed: Option<u64>) -> Result<BootstrapCIResult>`.
- `BootstrapCIResult { estimate, se, conf_int_lower, conf_int_upper, conf_level, n_bootstrap: usize }`; errors: fewer than
  2 observations, n_bootstrap < 2, conf_level outside (0, 1). The mean closure used inside `bootstrap_mean_ci` is
  `|s: &[f64]| s.iter().sum::<f64>() / s.len() as f64` — reuse exactly this expression for `statistic="mean"` so
  the two builders produce bit-identical replicates for the same seed.
Output-field naming follows the project convention `ci_lower` / `ci_upper` (proportion, correlation, ICC, TOST
structs), not upstream's `conf_int_*`.

Ruff: new Python files pass full `uv run ruff check`; modified files pass `uv run ruff check --select F,E9`.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
