## Implementation Decisions

### User instruction
"add these new functionality and update everything that is necessary." Treat this as full API coverage of the new upstream surface.

### Scope resolutions
- **RANSAC:** expose inference on the PyModel (`compute_inference`, `confidence_level`, inference getters, inlier-fit statistics). If a RANSAC polars expression already exists, add the same options there. Do not invent expression families that do not already exist for a model.
- **bootstrap_ci:** the upstream closure cannot cross FFI. Expose a fixed statistic dispatch (`"mean" | "median" | "std"`) plus `bootstrap_mean_ci` with `block_length`. No Python callbacks.
- **Bundled skills:** Phase 16 (wheel bundling) runs after this phase, so only the source skills under `plugins/polars-statistics/skills/` are updated. Do not create `python/polars_statistics/_plugin/`.
- **Package version:** unchanged. The 0.8.0 bump belongs to Phase 17. CHANGELOG gets an unreleased-section entry, including a "Behaviour changes" section.
- **Schema changes:** additive only (new functions, new trailing struct fields, new keyword arguments with defaults). Existing output structs are not reshaped.

### Execution order
16.1 runs before 16, so the wheel bundles the updated skills.
